# India Flood Risk Perception Gap

Data, model, and code associated with the manuscript *"Mismatch between perceived and assessed flood risk"*.

The paper produces the first district-level national map of the gap between perceived and assessed flood risk in India, identifying where public perception lags behind actual flood severity. This repository holds the post-processing, poststratification, and figure-generation pipeline used in the study.

## What this repo contains

* [`artifacts/`](artifacts/) — data (raw, processed, and output) and fitted models
* [`scripts/`](scripts/) — data preparation and modeling code
* [`figures/`](figures/) — main text and supplementary figures
